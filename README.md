# Classification Project

This project is a **Machine Learning classification project** where I used Logistic Regression to classify the given data into different classes.

### What I Did

* Split the data into training and testing sets
* Trained a Logistic Regression model
* Checked training and testing accuracy
* Created a confusion matrix to see the model's predictions

### Model Performance

* Training Accuracy: **84.81%**
* Testing Accuracy: **84.87%**

The confusion matrix shows how many samples were correctly and incorrectly classified for each class.

### Tools Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Jupyter Notebook

### Conclusion

The model achieved around **85% accuracy** on the test data, giving a good starting result for this classification problem.
